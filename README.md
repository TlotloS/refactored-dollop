# RazerClean Carpet n Upholstery Cleaning — Landing Page

A fast, responsive, single-page marketing site for **RazerClean Carpet n Upholstery Cleaning**.

> **Fresh Spaces. Cleaner Living.**

Professional carpet, upholstery, mattress deep cleaning, stain removal, water extraction
and pre- & post-occupational cleaning services in Gauteng.

## Features

- 📱 Fully responsive (mobile, tablet, desktop) with a mobile nav
- 🎨 Self-contained — all graphics are inline SVG, no external image/CDN dependencies
- 🧼 Sections: Hero, services, why-choose, about, contact and a quote-request form
- 💬 Quote form sends straight to **WhatsApp** (or email as a fallback)
- ⚡ Zero build step — plain HTML, CSS and vanilla JS

## Structure

```
index.html            # Page markup + inline SVG illustrations
assets/css/styles.css # Styling and responsive layout
assets/js/main.js     # Mobile nav + quote-form -> WhatsApp/email
```

## Running locally

It's a static site — just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
